# Evidence model and uncertainty

## Identity and ownership

Strict identity resolution uses exact normalized current/historical emails, phones,
hashes and stable references, with the time each statement became known. It does not
fuzzily join names or derive unsupplied hashes. Discontinuous histories and shared
aliases remain diagnostic. A later snapshot is not rolled backward using future facts.

The correlator expands only from the resolved subject: direct identifiers, file/service
scoped traces, one hop through typed resource references, then versions of established
resources. A newly encountered subject never starts another search. Foreign ownership
intervals, conflicting subjects, incompatible collections and unscoped references
prevent promotion to confirmed ownership. OCR identity requires an independent anchor.

The submission evidence index additionally derives SHA-256 hashes of historical emails
and accepts full names only when uniquely owned. Its workflow matcher uses observed
cadence and reported-result consistency as inference. Competing requests from both
participant request files participate in elimination. Ambiguous assignments stay out
of output steps; diagnostics say whether a viable assignment could flip the status.

## Provenance and clocks

Every observation retains participant evidence ID, digest, source origin, exact locator,
raw fields and source timestamps. Business deadlines describe policy, not observation
availability. An operation-success message is a claim, not a readback of resulting state.

Strict reconstruction uses the latest dependency clock: source observation/record,
manifest capture, packaging and catalogue linkage must all be known by `audit_at`.
A later file cannot establish earlier ownership or state. Physical replicas remain
separate; a newer primary read cannot erase a surviving replica. Simultaneous field or
state contradictions remain recorded even after a later resolution.

## Presence and treatment

Exact negative resource reads can prove absence. Broad subject searches, filters,
failed reads and search results naming another record cannot. Strict omission proof
requires an explicit complete, unfiltered, untruncated listing of the known collection;
a schema, row count or empty array alone does not suffice. Unknown schema/category,
partial identifier projections and missing policy conditions remain unknown.

Redaction preserves policy-required records. An account tombstone must retain the
permitted stable reference while removing prohibited direct identifiers. Anonymization
also removes linkage to the subject. Backup existence and restoration permission are
independent dimensions; active data flows and unsafe restores precede record cleanup.
A retained record that is missing cannot be repaired with an invented restore operation.

## Distinct confidence contracts

Strict audit abstains when no grounded official row can be justified. A supported
violation may produce an INCOMPLETE row while diagnostic obligations remain unresolved;
that row does not prove exhaustive discovery. COMPLETE requires proven treatment and
all confirmed obligations to be compliant.

Submission must supply one official answer for each request. It treats supplied SQL
and named JSON snapshots as inventories, prefers case-linked snapshots, and selects
state observed between request and audit. If every assessment lacks such a state, it
uses the existing pre-request fallback. It can use later identifier links for resource
attribution; those later files never become state citations. It may classify a case
COMPLETE from proven compliant resources while unknown or ambiguous resources remain
outside the row. These are inherited inference assumptions, not new strict guarantees.

The structural refactor deliberately preserves those assumptions, including low
confidence and all abstentions. They remain technical uncertainty, rather than being
hidden by a higher sample score. See the official evaluation report for examples.

Citation checks establish existence, availability and linkage. They cannot, by
themselves, prove ownership, state truth, policy applicability or complete discovery.
